# CNN Image Classification

A collection of Jupyter notebooks demonstrating image classification with **Convolutional Neural Networks (CNNs)** using Python, TensorFlow and Keras.

## Projects

- **MNIST:** handwritten digit classification using grayscale 28 × 28 images.
- **CIFAR-10:** image classification across 10 object categories using 32 × 32 colour images.

## Techniques and tools

- Convolutional layers (Conv2D)
- Max pooling
- Flatten and dense layers
- ReLU and softmax activations
- Dropout regularization
- Model training and validation
- Confusion matrix and classification report for evaluation

## Repository contents

- `project1.ipynb` — MNIST and CNN image-classification practical.
- `project2.ipynb` — CIFAR-10 CNN classification practical.

## Getting started

1. Clone or download this repository.
2. Open the notebooks in Jupyter Notebook, JupyterLab or Google Colab.
3. Run the cells in order. The notebooks load their datasets through the Keras dataset utilities.

## Technologies

Python · TensorFlow · Keras · NumPy · Matplotlib · Seaborn · scikit-learn
